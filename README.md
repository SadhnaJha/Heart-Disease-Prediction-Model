# **Heart Disease Prediction Model :-**

A beginner-friendly Machine Learning project that predicts the likelihood of heart disease using Logistic Regression.

📌 **Project Overview :-**

This project predicts heart disease based on patient health features using a classification model.

🛠️ **Technologies Used :-**

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Logistic Regression

🔍 **Steps :-**

1. Load the heart disease dataset.
2. Separate features and target.
3. Split data into training and testing sets.
4. Scale the features using StandardScaler.
5. Train the Logistic Regression model.
6. Predict the outcome.
7. Evaluate the model using Accuracy, Precision, Recall, and Confusion Matrix.
8. Display the ROC Curve.

📊 **Output :-**

* Accuracy
* Precision
* Recall
* Confusion Matrix
* ROC Curve

🎯 **Learning Outcome :-**
This project helped me to learn classification, feature scaling, model training, prediction, and model evaluation** using Logistic Regression.
